# RC Smart Pit-Stop - MVP Ideas

### Main problem
Manual analysis of data coming from autonomus RC vehicles and checking their mechanical condition is time consuming, which leads to unstable and unrelaiable fleet.

### Minimal set of features
- Fleet management (registering/removing vehicles, recalling vehicles to base)
- Fleet manager accounts - as users
- Fleet overview
- Vehicle details view
- Live vehicle status overview
- Smart Pit-Stop logic to manage vehicle repairs or return to base when specific conditions are met

### What's NOT included in MVP
- Fleet mechanic profiles (mechanics can only view assigned vehicles that require repair)
- Analysis of the vehicle's battery usage history
- Analysis of the vehicle's failure history
- Historical vehicle status overview

### Success criteria
- 80% of vehicles return for automatic inspections and battery charging 
- Mechanics spend 70% less time walking around a broken-down or dead vehicle
